# Bookbuddy

A polished static reading app experience built for Vercel.

## Run locally

```bash
npm install
npm run dev
```

Then open: http://localhost:3000

## Deploy to Vercel

1. Push this repository to GitHub.
2. Import it into Vercel.
3. Use the default settings.
4. Vercel will serve the static files from the repository root.

## Features

- Smart library dashboard
- Reading progress tracking
- Highlights and notes
- Search and tags
- Private mode toggle
- Reading streak and stats
- Responsive, polished UI for desktop and mobile
